# Trigger Map

## Forcas que movem o usuario

| Forca | Evidencia na interface | Decisao de design |
| --- | --- | --- |
| Evitar esquecimento | Cards de atrasadas e proximas doses | Status vacinal deve aparecer no dashboard, lista e detalhe |
| Agir rapido | CTA de registrar vacina | Acoes principais ficam no topo e usam icones |
| Confiar nos dados | Historico por pet | Datas, status e origem dos registros precisam ser legiveis |
| Entender sem treino | Empty states e textos curtos | Linguagem direta, sem termos tecnicos desnecessarios |
| Demonstrar projeto | Rotas e fluxos claros | Navegacao previsivel e documentacao alinhada |

## Prioridade de features pelo impacto

1. Dashboard com resumo vacinal.
2. Lista de pets com filtro/status.
3. Detalhe do pet com historico.
4. Cadastro de pet.
5. Registro de vacina.
6. Alertas simulados.
