# Responsividade e Acessibilidade

- Projete primeiro para 360 px e valide tambem 768 px e 1280 px.
- Nao dependa de rolagem horizontal para tarefas principais.
- Tabelas operacionais devem ter representacao em cards no mobile.
- Controles interativos devem ter alvo minimo de 44 px quando possivel.
- Use elementos semanticos, foco visivel, labels persistentes e `aria-live` em feedback dinamico.
- Todo fluxo deve cobrir loading, vazio, erro, sucesso e desabilitado.
- Animacoes devem respeitar `prefers-reduced-motion`.
