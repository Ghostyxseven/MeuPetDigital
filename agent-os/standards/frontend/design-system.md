# Design System Frontend

- Use os artefatos em `design-artifacts/` como contrato visual do produto.
- Use marrom e bege como identidade primaria; `amber` para proximidade e `red` para atraso.
- Os aliases legados `emerald` e `teal` representam os tokens marrom/bege neste projeto.
- Reutilize componentes de `src/core/components` antes de criar estilos locais.
- Mantenha corpo em `text-sm` e informacoes criticas em pelo menos `text-xs`.
- Use raios `rounded-xl` nos controles e `rounded-2xl` apenas em paineis de destaque.
- Todas as mensagens visiveis devem usar portugues brasileiro natural e acentuado.
